# 🌐 Personal Portfolio Website

## 📌 Project Description

**Personal Portfolio Website** is a responsive and modern website created to showcase my skills, projects, experience, and professional profile.

The portfolio provides an easy way for recruiters and visitors to learn about my technical skills, explore my projects, and get in touch with me.

## ✨ Features

* 🏠 **Hero Section** – Introduction with professional profile
* 👩‍💻 **About Me** – Personal and professional information
* 🛠️ **Skills Section** – Showcase of technical skills
* 💼 **Projects Section** – Display of completed projects
* 📬 **Contact Section** – Contact information and communication form
* 📱 **Responsive Design** – Compatible with desktop, tablet, and mobile devices
* ✨ **Animations & Hover Effects** – Interactive and modern user experience
* 🧭 **Smooth Navigation** – Easy navigation between portfolio sections

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and animations
* **Bootstrap 5** – Responsive layout and components
* **JavaScript** – Interactions and dynamic functionality

## 🎨 Design

The portfolio uses a modern and clean design with:

* Responsive layout
* Professional typography
* Gradient backgrounds
* Interactive buttons
* Hover effects

* Modern project cards

```bash id="l3e2yq"
git clone YOUR_GITHUB_REPOSITORY_LINK
```

2. Open the project folder.
3. Open `index.html` in your browser.

### Option 2: Using VS Code

1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.
